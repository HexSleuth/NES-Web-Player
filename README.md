## 🚀 Quick Start

### Just want to play?
👉 **<https://hexsleuth.github.io/NES-Web-Player/>**

### Run it locally

```bash
# 1 — Clone
git clone https://github.com/hexsleuth/NES-Web-Player.git
cd NES-Web-Player

# 2 — Serve (any static server works)
npx serve .
#   or:  python3 -m http.server 8080

# 3 — Open
open http://localhost:3000
```

⚠️ Open it over HTTP(S), not file:// — audio worklets and WASM need a proper origin.

Deploy your own

```bash
# Fork → Settings → Pages → Source: Deploy from branch → main / (root)
```

That's it. Every push to main redeploys in ~30 seconds.

### Design Highlights for a Mobile-First README

The layout prioritizes quick scanning and smooth performance on small screens, while still feeling playful.

- **Animated identity at the top** — A waving capsule header and typewriter-style SVG give the page an instant retro arcade feel without any JavaScript.
- **Real-time badge cluster** — Live site status, visitor counts, and GitHub repo stats are grouped into a compact strip, so the README feels current at a glance.
- **Mobile-first touch layout** — Sections use centered tables and stacked content blocks that reflow cleanly on narrow screens, matching the player's own touch-friendly controls.
- **Playful retro details** — The gradient dividers, pixel-style footer, and optional contribution snake keep the page visually engaging without becoming heavy.
- **Clear quick-start path** — Local setup, deploy, and embed snippets are separated into short, copy-friendly blocks so users can go from reading to playing in seconds.
